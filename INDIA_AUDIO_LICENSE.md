# India Hit Chant Audio Pack

The `印度人` preset uses four **original procedurally generated** WAV files created for this project:

- `sounds/india/india-reaction-1.wav`
- `sounds/india/india-reaction-2.wav`
- `sounds/india/india-reaction-3.wav`
- `sounds/india/india-reaction-4.wav`

Each file follows the interaction pattern: impact → short vocal exclamation → original repeated “du” syllable chant → Dhol-style drum ending.

The pitch patterns and synthesis are original and are **not a transcription, sample, or recreation of Daler Mehndi's “Tunak Tunak Tun.”** No recording from that song is bundled.
